命名ルール
utm_source = 配布場所・プラットフォーム、utm_medium = 媒体タイプ、utm_campaign = IT健康診断、utm_content = 個別制作物・バージョン。

例：交流会で配るA4初版 → entrepreneur_meetup / print / it_health_check / a4_v01
Xの2投稿目 → x / social / it_health_check / post02
